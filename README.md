# 加拿大留学生预算计算器

一个纯前端的月度预算工具：把每学期学费折算为月支出，汇总生活费和多项收入，并展示结余、支出占比与预算提示。

仓库沿用历史名称 `pdf-to-text-tool`，当前版本提供预算计算功能，没有 PDF 转文本功能。

## 使用

直接用浏览器打开 `index.html`，无需安装依赖或构建。填写的金额单位为 CAD；初始数值仅为示例，不代表当地价格标准。

- 支持添加、删除收入来源。
- 每项月支出先四舍五入到分，再计算总额。
- 数据仅在当前浏览器页面中计算，不上传，也不持久保存；刷新会恢复示例。
- 页面没有外部脚本或字体。Excel 版本链接会打开外部商店。

## 维护

全部 HTML、CSS 和 JavaScript 都在 `index.html` 中。修改后检查手机及桌面布局、零支出、收支平衡、负数或超上限输入、收入添加和删除，以及学期月数切换。无效数值的临时估算规则显示在页面中。

金额先转成整数分，再按月折算并四舍五入，避免二进制浮点误差使半分向下取整（如 2.01 CAD ÷ 6 个月应为 0.34 CAD/月）。

## 测试

`tests/budget.test.js` 用 Playwright 的 Chromium 打开 `index.html`，检查默认示例总额、学费按分取整、负数/空值/超上限输入、全零预算、收入增删与表单标签，并确认页面没有脚本错误或 NaN。

```bash
npm ci
npx playwright install chromium
npm test
```

GitHub Actions 的 `test` 工作流在每次推送和 PR 时运行同样的测试。

## 部署

纯静态页面，无构建步骤、无环境变量、无后端。把 `index.html` 上传到任意静态托管即可（如 GitHub Pages：Settings → Pages → Deploy from a branch → `main` / root）。`package.json`、`package-lock.json` 和 `tests/` 只用于测试，不影响页面；若托管平台（Vercel / Netlify）检测到 `package.json`，构建命令留空、输出目录设为仓库根目录即可。

| 环境变量 | 说明 |
|---|---|
| （无） | 页面不读取任何环境变量或密钥 |
